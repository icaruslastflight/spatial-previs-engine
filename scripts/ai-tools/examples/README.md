# Curated example outputs

Empty by design, not an oversight. This project's showcase convention
(CLAUDE.md §12) is "no mocked data, no stand-ins" — populating this directory
with a hand-written transcript that merely *looks like* real `metaprompt.py`
output would violate that on the first file in it.

Once you've run `python scripts/ai-tools/metaprompt.py draft --task "..."`
for real and like the result, copy the saved file from
`scripts/ai-tools/prompts/` in here (that directory is git-ignored;
this one isn't) as a genuine, committed reference example.
